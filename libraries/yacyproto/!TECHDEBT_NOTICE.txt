TECHDEBT NOTICE - yacyproto needs a refactor

Cognitive complexity is high and the package exports more than it should.

The package must export only protocol request and response structs and
the functions that encode and decode them.

The current API also exports standalone field names, paths, endpoint
method sets, authentication functions, and response header functions.
These exports spread protocol vocabulary and encoding rules across the
packages that use yacyproto.
